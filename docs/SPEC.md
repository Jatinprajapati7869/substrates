# SPEC

Each scenario has an id, actor, trigger, result, failure behavior, and the evidence we accept. Status values: `proven` (automated test or recorded command), `manual` (needs a human or production), `open`. Update status in `docs/PROGRESS.md`, not here, unless the scenario itself changes.

| Id  | Actor               | Trigger                                                             | Result                                                                                                                                 | Failure                                                                                 | Evidence                                               |
| --- | ------------------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| S1  | Visitor             | GET `/` with missing Firebase env                                   | Page still renders or shows a branded error, never a bare 500                                                                          | Health route reports which env group is missing (names only)                            | `npm test` env test; `GET /api/health`                 |
| S2  | Visitor             | Sign in with Google or email                                        | Account loads, profile doc exists at `profiles/{uid}`                                                                                  | Error shown on `/signin`, no loop                                                       | `src/test/` account tests; manual live check           |
